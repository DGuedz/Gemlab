# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

---

## [1.1.0] - 2024-12-08

### ✨ Adicionado
- Página **Equipe & Parceiros** completa com 8 membros da equipe
- Sistema de 4 Pilares da plataforma (Rastreabilidade, Governança Fiscal, Sustentabilidade, Equipe & Parceiros)
- Integração de fotos reais dos membros da equipe
- Seção COOPESMERALDA com métricas e conquistas
- Seção Associação Benjamim Cristã (ABC) com projetos de impacto social
- Badge "Tech Lead" para Diego Guedes

### 🔄 Alterado
- Pivot de posicionamento: de "Plataforma de Investimento" para "Empresa de Tecnologia e Certificação Científica"
- Atualização da identidade visual para "Protocolo de Confiança para Mineração 4.0"
- Reorganização da navegação com 4 Pilares

### 🐛 Corrigido
- Erros de import de componentes na página Equipe & Parceiros
- Problemas de renderização de fotos dos membros da equipe

---

## [1.0.0] - 2024-11-15

### ✨ Adicionado
- **Lançamento Inicial do GEMLAB Protocol**
- Sistema de verificação SpectralHash
- Integração com EAS (Ethereum Attestation Service)
- Dashboard de usuário completo
- Sistema de certificação gemológica
- QR Code verification system
- Modal de compartilhamento de certificados
- Página institucional com manifesto
- Hero Protocol com Tríade de Confiança
- Sistema de dark mode
- Autenticação via Supabase
- Analytics com Google Analytics 4
- Design system com Tailwind CSS v4
- Componentes shadcn/ui

### 🔐 Segurança
- Implementação de Row Level Security (RLS) no Supabase
- JWT token authentication
- Secure wallet connection

### 📚 Documentação
- README.md com instruções de setup
- Documentação do Oracle Fiscal
- Design System Reference
- Auth System documentation

- Configuração Vite + React + TypeScript
- Setup de Tailwind CSS
