##  Checklist

<!-- Marque com 'x' cada item completado -->

### Código
- [ ] Meu código segue o style guide do projeto
- [ ] Realizei uma auto-revisão do meu código
- [ ] Comentei código em áreas complexas ou não-óbvias
- [ ] Minhas mudanças não geram novos warnings
- [ ] TypeScript compila sem erros (`npm run type-check`)
- [ ] Linter passa sem erros (`npm run lint`)

### Testes
- [ ] Adicionei testes que provam que minha correção é efetiva ou que minha feature funciona
- [ ] Testes novos e existentes passam localmente com minhas mudanças
- [ ] Testei em diferentes navegadores (Chrome, Firefox, Safari)
- [ ] Testei responsividade (mobile, tablet, desktop)

### Documentação
- [ ] Atualizei a documentação relevante (README, docs/, etc)
- [ ] Atualizei comentários no código
- [ ] Atualizei o CHANGELOG.md (se aplicável)

### Segurança & Compliance
- [ ] Não incluí secrets, API keys ou credenciais
- [ ] Verifiquei implicações de segurança das mudanças
- [ ] Considerei impacto em compliance (CVM, RFB) se aplicável
- [ ] Código segue princípios de privacy-by-design

### Smart Contracts (se aplicável)
- [ ] Contrato auditado ou revisado por segurança
